# IMMY

Пиксельный 2D-файтинг в стиле классических аркад — на **чистом Python** (только стандартная библиотека, интерфейс на `tkinter`). Палитра: красный, оранжевый, золотой.

## Запуск

```bash
python3 main.py
```

Требуется Python 3.8+ с tkinter (на Windows/macOS встроен, в Linux: `sudo apt install python3-tk`).

## Геймплей

- Бой с ботом: 2 раунда, побеждает взявший 2 раунда. Во втором раунде бот сильнее.
- Уровень бота растёт с каждой вашей победой — бот становится быстрее, злее и точнее.
- Каждый 10-й уровень — **БОСС**: увеличенная модель, больше здоровья, сильнее атаки.
- Награда за победу: `50 × уровень` монет, за босса — `100 × уровень` (×2).
- **Карты арен выбираются случайно** в начале каждого боя: ВУЛКАН, ЛЕДНИК, ПУСТЫНЯ, НОЧНОЙ ЛЕС, МИР ТЕНЕЙ.
- **Музыка**: чиптюн в меню и отдельный боевой трек во время боя. Клавиша `M` — вкл/выкл.
- Прогресс (монеты, уровень бота, купленные бойцы) сохраняется в `immy_save.json`.

## Управление

| Клавиша | Действие |
|---|---|
| A / D | движение (работает и на русской раскладке: Ф/В) |
| W | прыжок (Ц на русской раскладке) |
| S | присед — уворот от небесных атак (Ы на русской раскладке) |
| ЛКМ | обычная атака (серия из 3 ударов с растущим уроном) |
| 1 / 2 / 3 | способности |
| M | музыка вкл/выкл |
| ESC | выход в меню |

## Магазин

Первые 3 бойца — стандартные, доступны сразу. Остальные бойцы редкости «обычный» продаются в магазине за **500 монет** каждый. Нажмите на карточку бойца, чтобы купить его. Другие редкости будут добавлены позже.

## Бойцы (13)

**Стандартные:**
- **DEADY** — жнец душ. Бросок косы (возвращается через 3 с, без косы атак нет), костлявая рука из-под земли, мир душ с телепортом за спину врага.
- **LIGHTY** — человек-молния. Электрошок (оглушение 2 с), небесная молния (уворот — присед), вспышка (−60% получаемого урона на 3 с).
- **EMBERY** — пламенный берсерк. Огненный шар, столп пламени (уворот — прыжок), ярость (+50% урона на 5 с).

**Обычные (500 монет в магазине):**
- **FROSTY** — ледяная королева. Ледяной осколок, ледяной шип, ледяная броня.
- **TOXINY** — отравитель. Ядовитый плевок, ядовитое облако, токсичный транс.
- **SHADOWY** — убийца из тени. Теневой клинок, шаг сквозь тень (телепорт за спину), пелена тьмы.
- **STONY** — каменное сердце. Каменный удар (оглушение), землетрясение, каменная кожа.
- **WINDY** — хозяйка бури. Порыв ветра, смерч, кружение.
- **SANDY** — повелитель песков. Песчаный снаряд, песчаная буря, песчаный двойник (телепорт).
- **SOLARY** — жрица солнца. Солнечный луч, столп света (уворот — присед), ореол.
- **LUNARY** — дева луны. Лунный серп, лунная волна, исцеление луной.
- **NECROY** — владыка мёртвых. Череп-снаряд, кладбищенские руки, вампирская аура.
- **PIXY** — искра леса. Волшебная пыльца, разряд пыльцы (оглушение), феичий прыжок (телепорт).

## Структура

```
main.py          — точка входа
selftest.py      — самопроверка логики без дисплея (python3 selftest.py)
immy/
  config.py      — константы, шрифты, палитра
  util.py        — lerp/clamp/градиенты
  heroes.py      — данные бойцов и способностей
  save.py        — сохранение прогресса (монеты, уровень, купленные бойцы)
  particles.py   — частицы с лимитами, угольки, всплывающий урон
  background.py  — карты арен, фоны, иконки, факелы
  sound.py       — процедурная чиптюн-музыка (WAV-синтез, без файлов)
  fighter.py     — боец: физика, комбо, рендер
  ai.py          — ИИ бота с уклонениями
  arena.py       — бой, раунды, способности, снаряды, HUD
  ui.py          — кнопки, монеты
  game.py        — окна, ввод, магазин, главный цикл
```
