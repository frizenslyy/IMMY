# IMMY

Пиксельный 2D-файтинг в стиле классических аркад — на **чистом Python** (только стандартная библиотека, интерфейс на `tkinter`). Палитра: красный, оранжевый, золотой.

## Запуск

```bash
python3 main.py
```

Требуется Python 3.8+ с tkinter (на Windows/macOS встроен, в Linux: `sudo apt install python3-tk`).

## Геймплей

- **Бой с ботом**: 2 раунда, побеждает взявший 2 раунда. Во втором раунде бот сильнее.
- **Уровни и EXP**: опыт даётся в каждом режиме (победы, выживание, кампании, добивания). Уровень игрока открывает кампании и показывает прогресс в меню.
- Уровень бота растёт с каждой вашей победой — бот становится быстрее, злее и точнее.
- Каждый 10-й уровень — **БОСС**: увеличенная модель, больше здоровья и урона (сбалансирован: ×1.35 HP, ×1.15 урона — напряжёт, но победим).
- **Умный ИИ**: бот не просто сильнее — он **думает**: выбирает тактику (рывок или размен на дистанции), наказывает за оглушение и обездвиживание (комбо-пуны), использует спецприёмы и ульты по кулдаунам, уклоняется от наземных и небесных атак.
- **ВЫЖИВАНИЕ** — режим волн для фарма монет: бесконечные волны врагов, каждая 5-я волна — **мини-босс**. За убитого воина **+50 монет**, за мини-босса **+100**, плюс бонус за волну. Между волнами игрок восстанавливает 40% здоровья. Награда за забег сохраняется даже при поражении.
- **КАМПАНИИ** — 3 кампании по 10–15 ступеней с нарастающей сложностью, финальная ступень — **БОСС кампании**. За первое прохождение — монеты, за финал — **эксклюзивный боец**. Режим открывается на **5 уровне игрока**:
  - **КРОВАВЫЙ ЗАМОР** (10 ступеней) → награда: **GHOULEY**
  - **ПЕПЕЛЬНЫЕ ПУСТОШИ** (12 ступеней) → награда: **ASHY**
  - **ТРОН ПЛАМЕНИ** (15 ступеней) → награда: **PYROY**
- **ДОБИВАНИЯ (ульты)**: у эпических и эксклюзивных бойцов 4-я способность — ульт. Когда у врага **меньше 10% HP** и он в радиусе ульты, запускается красивая анимация добивания в стиле персонажа:
  - у врага остаётся **ровно 1 удар** HP;
  - если HP врага **ниже 5%** — добивание **убивает полностью** (**качественное добивание**: бонусные монеты и EXP);
  - VAWYY закручивает врага в водоворот и разрывает, GALAXY затягивает в чёрную дыру, GHOULEY пожирает, ASHY испепеляет, PYROY поглощает адским пламенем.
- **Динамическая боевка**: парирование на `F`, **критические удары** (шанс зависит от ловкости, ×1.8 урона), отбрасывания, хитстоп и тряска камеры, цветные дуги ударов по стадиям комбо.
- **Спецприёмы**: у каждого бойца свои комбо-приёмы (`A+S`, `W+S`, `W+A`, `W+D` — нажать одновременно). Нужны **энергия** (золотая шкала в HUD, копится за попадания) — и теперь ещё **перезарядка у каждого приёма**. В бою спецприёмы показаны **слева экрана** простыми кнопками с таймером КД. У обычных бойцов — 2 спецприёма, у необычных/эпических/эксклюзивных — 3.
- **Статы бойцов**: СИЛА (урон), ЛОВКОСТЬ (шанс крита + окно парирования), СКОРОСТЬ (передвижение) — видны в меню выбора героя и влияют на бой.
- **Музыка**: чиптюн в меню и отдельный боевой трек во время боя. Клавиша `M` — вкл/выкл.
- **Достижения**: 45 достижений с наградами в монетах — вкладка «НАГРАДЫ» в меню (победы, боссы, волны, спецприёмы, ульты, добивания, парирования, комбо, покупки, кампании, уровень).
- Прогресс (монеты, уровень игрока и бота, EXP, купленные бойцы, кампании, достижения, статистика) сохраняется в `immy_save.json`.

## Управление

| Клавиша | Действие |
|---|---|
| A / D | движение (работает и на русской раскладке: Ф/В) |
| W | прыжок (Ц на русской раскладке) |
| S | присед — уворот от небесных атак (Ы на русской раскладке) |
| ЛКМ | обычная атака (серия из 3 ударов с растущим уроном) |
| 1 / 2 / 3 / 4 | способности (4-я — у редкостей «необычный» и выше) |
| A+S / W+S / W+A / W+D | **спецприём** — требует энергии и имеет перезарядку (свой для каждого героя, см. вкладку ГЕРОИ) |
| F | **парирование** — при точном тайминге враг оглушён на 0.1 с, а вы контратакуете (А на русской раскладке) |
| ← / → / ↑ / ↓ | стрелки дублируют A/D/W/S |
| M | музыка вкл/выкл |
| ESC | выход в меню |

Работает и на русской раскладке: Ц/Ы/Ф/В — WASD, А — парирование (стрелки тоже работают).

## Магазин

Первые 3 бойца — стандартные, доступны сразу. Остальные редкости покупаются в магазине кликом по карточке:
- **ОБЫЧНЫЙ** — **500 монет**, 3 способности + 2 спецприёма, сумма статов 14.
- **НЕОБЫЧНЫЙ** — **2000 монет**, 4 способности (уникальные механики: паутина, призыв, яд, крит-удар, притягивание, луч, гейзер, вихрь, прилив), сумма статов 17, 3 спецприёма.
- **ЭПИЧЕСКИЙ** — **5000 монет**, 4 абсолютно новые способности, 4-я — **ультимативное добивание**, сумма статов 19, 3 спецприёма.
- **ЭКСКЛЮЗИВНЫЙ** — не продаётся, награда за прохождение кампании. Как необычный, но с ультой.

## Бойцы (28)

**Стандартные:**
- **DEADY** — жнец душ. Бросок косы (возвращается через 3 с, без косы атак нет), костлявая рука из-под земли, мир душ с телепортом за спину врага.
- **LIGHTY** — человек-молния. Электрошок (оглушение 2 с), небесная молния (уворот — присед), вспышка (−60% получаемого урона на 3 с).
- **EMBERY** — пламенный берсерк. Огненный шар, столп пламени (уворот — прыжок), ярость (+50% урона на 5 с).

**Обычные (500 монет в магазине):**
- **FROSTY** — ледяная королева. Веер ледяных осколков, **ледяные шипы из земли** (волна), ледяная броня.
- **TOXINY** — отравитель. Ядовитый плевок, ядовитое облако, токсичный транзит.
- **SHADOWY** — убийца из тени. Теневой клинок, шаг сквозь тень (телепорт за спину), пелена тьмы.
- **STONY** — каменное сердце. Каменный удар (оглушение), землетрясение, каменная кожа.
- **WINDY** — хозяйка бури. Порыв ветра, смерч, кружение.
- **SANDY** — повелитель песков. Песчаный снаряд, песчаная буря, песчаный двойник (телепорт).
- **SOLARY** — жрица солнца. Солнечный луч, столп света (уворот — присед), ореол.
- **LUNARY** — дева луны. Лунный серп, лунная волна, исцеление луной.
- **NECROY** — владыка мёртвых. Череп-снаряд, кладбищенские руки, вампирская аура.
- **PIXY** — искра леса. Волшебная пыльца, разряд пыльцы (оглушение), феичий прыжок (телепорт).

**Необычные (2000 монет, 4 способности):**
- **BANEY** — человек, мутировавший в паука. Паутина (обездвиживает на 1 с), призыв паучков-помощников, яд (процент от макс. HP за 4 с), паучий удар хвостом (гарантированный крит).
- **MAGNEY** — магнитный титан. Метеор из глубин (тяжёлый удар), магнитное притягивание, металлическая броня, электромагнитный разряд.
- **CRYSTAY** — кристаллическая дева. Веер кристаллов, кристальный купол (полный блок), кристальный дождь, мерцание (телепорт).
- **INFERNOY** — пылающая ярость. Испепеляющий луч, огненная волна, перегрев (+60% урона), прыжок-метеор с ударной волной.
- **MIRAGEY** — мастер миражей. Шаг миража (телепорт), веер иллюзий, иллюзорные оковы, дар миража (лечение).
- **PLASMY** — плазменное ядро. Плазменный снаряд, ионный луч (присед — уворот), плазменный щит (полный блок), очаг плазмы под врагом (уворот — прыжок).
- **TEMPESTY** — грозовой владыка. Вихрь (выдёргивает врага к вам), шквал воздушных сечей, грозовой фронт (град разрядов, уворот — присед), разряд (оглушение).
- **BONESY** — некромант-скелет. Костяное копьё, рука из могилы (уворот — прыжок), призыв костей, костяной саркофаг (полный блок).
- **SPECTRY** — призрак. Порыв духа (веер из трёх сгустков), сквозь стену (телепорт за спину), холод могилы (вампиризм 50%), стены духа (ряд столпов, уворот — прыжок).
- **BEASTY** — оборотень. Рвущий удар (гарантированный крит), прыжок хищника с ударом по области, звериная ярость (+45% урона), удар лапы в землю (уворот — прыжок).

**Эпические (5000 монет, 4-я способность — ульта):**
- **VAWYY** — водяной маг. Гейзер (подбрасывает врага в воздух), водоворот (затягивает и жмёт урон по тикам), цунами (стена воды через всю арену), **ГНЕВ ОКЕАНА** — вода закручивает врага в водоворот и разрывает.
- **GALAXY** — звёздный маг. Сингулярность (затягивает врага), комета с оглушением (уворот — присед), звездопад (уворот — присед), **ЧЁРНАЯ ДЫРА** — затягивает и разрывает врага.

**Эксклюзивные (награда кампаний):**
- **GHOULEY** — награда «Кровавого замора». Кровавый бросок (гарантированный крит), жажда крови (вампирская аура), могильная лапа, **ПИР ГУЛЯ** — пожирает ослабленного врага вблизи.
- **ASHY** — награда «Пепельных пустошей». Пепельная буря, огненный столп, пепельный покров (−55% урона), **СМЕРТНЫЙ ЖАР** — волна пепла испепеляет врага на расстоянии.
- **PYROY** — награда «Трона пламени». Огненный шторм, метеор, ярость пламени (+50% урона), **АДСКОЕ ВОПЛОЩЕНИЕ** — взрыв адского пламени вблизи.

## Структура

```
main.py          — точка входа
selftest.py      — самопроверка логики без дисплея (python3 selftest.py)
immy/
  config.py      — константы, шрифты, палитра, кривая EXP
  util.py        — lerp/clamp/градиенты
  heroes.py      — данные бойцов, способностей и спецприёмов
  save.py        — сохранение прогресса (монеты, EXP, кампании, достижения, статистика)
  campaign.py    — кампании: ступени, сложность, награды, разблокировка
  achievements.py— 45 достижений и их проверка
  particles.py   — частицы с лимитами, угольки, всплывающий урон
  background.py  — карты арен, фоны, иконки, факелы
  sound.py       — процедурная чиптюн-музыка (WAV-синтез, без файлов)
  fighter.py     — боец: физика, комбо, спец-КД, рендер
  ai.py          — ИИ бота: тактики, пуны, уклонения
  arena.py       — бой, раунды, способности, ульты, снаряды, HUD
  ui.py          — кнопки, монеты
  game.py        — окна, ввод, магазин, кампании, достижения, главный цикл
```
