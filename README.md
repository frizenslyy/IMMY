# IMMY

Пиксельный 2D-файтинг в стиле классических аркад — на **чистом Python** (только стандартная библиотека, интерфейс на `tkinter`). Палитра: красный, оранжевый, жёлтый, золото. Ретро-пиксельный стиль во всех экранах, аренах и анимациях.

Версия **7.0** — **АРТЕФАКТЫ** (30 шт., крафт из фрагментов), **зонные хитбоксы** (голова/тело/ноги), **30 арен с ловушками**, **сюжетные диалоги**, **MK-фаталити** (множество видов), **настройки** (шестерёнка), **SFX на всё**, **PLAY-подменю**, **build.bat**. 50 бойцов, 23 кампании (305 ступеней), 191 достижение.

## Запуск

```bash
python3 main.py
```

Требуется Python 3.8+ с tkinter (на Windows/macOS встроен, в Linux: `sudo apt install python3-tk`).

Окно **1600×900**, автоматически центрируется на экране. Частота обновления — **110 FPS**.

### Сборка exe (Windows)

`build.bat` в корне репозитория: перед сборкой сам подтягивает обновления из репозитория (`git pull --ff-only`), устанавливает PyInstaller при необходимости и собирает `dist\IMMY.exe`. Исходники остаются в папке — код можно править и пересобирать снова.

## Режимы

Все игровые режимы собраны в **PLAY-подменю** (кнопка PLAY в меню открывает сетку 2×3: VS БОТ, ВЫЖИВАНИЕ, CAMPAIGN, МУЧЕНИК, ONLINE, FRIEND).

- **VS БОТ** — бой с ботом: 2 раунда, побеждает взявший 2 раунда. Во втором раунде бот сильнее.
- **Уровень бота** растёт с каждой победой (+1): бот становится быстрее, злее и точнее. Каждые 10 уровней — **БОСС**: увеличенная модель, больше здоровья и урона (сбалансирован: ×1.35 HP, ×1.15 урона), награда с **множителем ×2**.
- **ВЫЖИВАНИЕ** — режим волн для фарма монет: бесконечные волны врагов, каждая 5-я волна — **мини-босс**. За убитого воина **+35 монет**, за мини-босса **+70**, плюс бонус за волну. Между волнами игрок восстанавливает 40% здоровья. Награда за забег сохраняется даже при поражении. С шансом **55%** (с мини-босса — **100%**) выпадают **фрагменты артефактов**.
- **CAMPAIGN** — 23 кампании (305 ступеней) с нарастающей сложностью, финальная ступень — **БОСС кампании**. После победы на ступени — кнопка **«СЛЕДУЮЩИЙ УРОВЕНЬ»** прямо на экране результата, без возврата в меню. Награды за первое прохождение: монеты, **самоцветы** или **эксклюзивные бойцы** (в более сложных кампаниях):
  - **КРОВАВЫЙ ЗАМОР** (10 ступеней) → **GHOULEY**
  - **ПЕПЕЛЬНЫЕ ПУСТОШИ** (12) → **ASHY**
  - **ТРОН ПЛАМЕНИ** (15) → **PYROY**
  - **ЛЕГИОН КОСТЕЙ** → **NECROMANCERY**
  - **РАЗЛОМ РЕАЛЬНОСТИ** → **CHAOSY**
  - **КУЗНЯ ТИТАНОВ** → **TITANY**
  - остальные — монеты и самоцветы.
- **EXP и уровни игрока**: опыт даётся в каждом режиме (победы, выживание, кампании, добивания). Уровень открывает кампании и растёт по кривой `80 + 40·уровень`.

## Боевка

- **Комбо**: серия из 3 ударов ЛКМ с растущим уроном **×1.0 → ×1.18 → ×1.4**. Окно комбо — 0.9 с.
- **Удары (система страйков)**:
  - **ЛКМ** — обычная атака (комбо из 3 ударов);
  - **E** — **пинок**: быстрый, отталкивает врага (КД 1.0 с);
  - **S + ЛКМ** — **апперкот**: всегда критический, **пробивает блок**, подбрасывает врага (КД 2.0 с);
  - **S + E** — **подсечка**: сбивает врага с ног (КД 1.2 с);
  - **ЛКМ в воздухе** — **удар в полёте** (КД 1.0 с);
  - **E в воздухе** — **dive-удар вниз** (пикирование на врага).
  - У каждого удара своё преимущество: пинок контролирует дистанцию, апперкот ломает защиту, подсечка наказывает стойку и блок, воздушные удары ловят приземляющегося врага.
- **Парирование на `F`**: при точном тайминге (окно 0.2 с) враг оглушён на **0.1 с**, а вы контратакуете.
- **Критические удары**: шанс зависит от ловкости, **×1.8** урона.
- **Спецприёмы**: у каждого бойца свои приёмы (`A+S`, `W+S`, `W+A`, `W+D` — одновременно). Нужны **энергия** (золотая шкала в HUD, копится за попадания) и **своя перезарядка у каждого приёма**. В бою показаны **слева экрана** простыми кнопками с таймером КД. У обычных бойцов — 2 спецприёма, у необычных/эпических/эксклюзивных — 3, у **мифических** и **DEVILY** — 4.
- **Миф-ульта (мифические + DEVILY)**: нажмите **1 и 4 одновременно**, когда обе способности не на перезарядке, **энергия ≥ 50** и у врага **≤ 25% HP**. У каждого мифического — своя анимация: ЦАРСТВО ТЕНЕЙ, РАЗЛОМ РЕАЛЬНОСТИ, УДАР ТИТАНА, ВОСКРЕСЕНИЕ АДА.
- **Добивания (ульты)**: у эпических и эксклюзивных 4-я способность — ульт. Когда у врага **меньше 10% HP** и он в радиусе ульты, запускается анимация добивания: у врага остаётся **ровно 1 удар** HP; если HP **ниже 5%** — добивание убивает полностью (**качественное добивание**: +25 монет и EXP). VAWYY закручивает в водоворот, GALAXY затягивает в чёрную дыру, BLADEY казнит серией разрезов, VENOMY накрывает волной заразы, MAGMAY взрывает лавой изнутри, GRAVY сжимает сингулярностью.
- **Травмы и кровь**: от ударов летит кровь; с шансом **4%** можно повредить врагу сустав или сломать кость — дебафф на раунд: −25% силы, −30% скорости, невозможность прыгать или блок способности. Травмы случаются и с вами.
- **Умный ИИ**: бот выбирает тактику (рывок или размен на дистанции), наказывает за оглушение и обездвиживание (комбо-пуны), использует спецприёмы и ульты по кулдаунам, уклоняется от наземных и небесных атак, строит связки.

## Управление

| Клавиша | Действие |
|---|---|
| A / D | движение (работает и на русской раскладке: Ф/В) |
| W | прыжок (Ц на русской раскладке) |
| S | присед — уворот от небесных атак (Ы на русской раскладке) |
| ЛКМ | атака (комбо из 3 ударов); в воздухе — удар в полёте |
| E | **пинок**; в воздухе — dive-удар (У на русской раскладке) |
| S + ЛКМ | **апперкот** — всегда крит, пробивает блок |
| S + E | **подсечка** |
| 1 / 2 / 3 / 4 | способности; **1+4** — миф-ульта (мифические и DEVILY) |
| A+S / W+S / W+A / W+D | **спецприём** — требует энергию, свой КД |
| F | **парирование** — оглушение врага на 0.1 с (А на русской раскладке) |
| ← / → / ↑ / ↓ | стрелки дублируют A/D/W/S |
| M | музыка вкл/выкл |
| ESC | выход в меню |

Работает и на русской раскладке: Ц/Ы/Ф/В — WASD, А — парирование, У — пинок (стрелки тоже работают).

## Меню

Главное меню: **PLAY**, **HEROES**, **SHOP**, **INFO**, **AWARDS** + **шестерёнка настроек** (справа внизу).

- **PLAY** — подменю всех игровых режимов (сетка 2×3): VS БОТ, ВЫЖИВАНИЕ, CAMPAIGN, МУЧЕНИК, ONLINE, FRIEND.
- **HEROES** — экран из 3 частей: сетка иконок всех 50 бойцов, анимированный превью-персонаж, панель с описанием, шкалами статов, способностями, спецприёмами и плюсами/минусами. У каждого бойца **СТАТС**: СИЛА (урон), ЛОВКОСТЬ (шанс крита + окно парирования), СКОРОСТЬ (передвижение). При выборе бойца — **3 слота артефактов** с отметкой совпадения природы (**+7%** к баффам).
- **INFO** — страницы: **УДАРЫ** (все техники ударов и их преимущества) и **МЕХАНИКИ** (комбо, парирование, энергия, спецприёмы, ми-ульты, травмы, добивания, зоны удара, ловушки, артефакты, выживание, кампании, сундуки).
- **МУЧЕНИК** — 3 раунда против врага с **×6 HP и ×4 урона**. Победа (взять 2 раунда) = **100 самоцветов**; даже поражение даёт монеты за нанесённый урон.
- **AWARDS** — достижения с пагинацией (16 на страницу).
- **SHOP** — вкладки **БОЙЦЫ**, **АРТЕФАКТЫ** (крафт из фрагментов) и **СУНДУКИ**.
- **Настройки (шестерёнка)** — громкость музыки и звуков (слайдеры), **бесшумный режим**, тряска экрана, кровь. Всё сохраняется в сейв и применяется мгновенно.
- **M** — музыка (меню/бой), вкл/выкл.

## Арены (30) и ловушки

**30 арен**, выбираются случайно при начале боя. На 18 аренах есть **ловушки**, работающие циклично (цикл 6 с, активность 1.6 с):
- **Шипы** у стен — урон 8–15 + кровотечение;
- **Пилы** — выезжают из пола по своей траектории;
- **Пламенные жерла** — вспышки огня из пола.

Ловушка бьёт обоих бойцов (свой кд на каждого), урон по зонам и кровотечение.

## Зонные хитбоксы

Попадания делятся по высоте на **ГОЛОВУ** (×1.30 урона + стан 0.12 с), **ТЕЛО** (×1.00) и **НОГИ** (×0.80 + замедление 0.9 с). Подсечка всегда бьёт по ногам; снаряды определяют зону автоматически по высоте попадания. Хедшоты учитываются в статистике и достижениях.

## Диалоги

В боях с ботом есть **сюжетные реплики**: вступительные фразы (у боссов — свои), насмешки ботов при комбо, парировании и касте способностей, реплики на победу/поражение и между раундами — в диалоговой панели во время интро боя.

## Артефакты (30)

**30 артефактов** трёх уровней сложности крафта. Крафтятся из **фрагментов** (эссенции света, тьмы, огня, земли, воды, ветра — дроп в выживании: шанс 55%, с мини-босса 100%) и **самоцветов**: чем сложнее крафт, тем сильнее бафф (сила, броня до −45% урона, стойкость к взрывам до −60%, прирост энергии, скорость, крит, вампиризм и др.).

- На бойца надевается **3 артефакта** при выборе героя в HEROES.
- Совпадение **природы артефакта** с природой бойца (огонь/свет/тьма/земля/вода/ветер — определяется по стилю героя) даёт **+7% ко всем баффам**.
- В сетевых боях (ONLINE/FRIEND) артефакты не применяются — полный баланс.

## ONLINE и FRIEND

- **ONLINE** — автоматический поиск противника: откройте вкладку ONLINE на обоих компьютерах — игра сама найдёт противника и соединит (UDP-поиск, полный баланс сил).

## FRIEND — бой с другом по локальной сети

- Кнопка **FRIEND** в меню: игра сама находит компьютеры в локальной сети (UDP-обнаружение) и показывает их списком — нажмите на компьютер друга, чтобы начать.
- Экран выбора — 4 части: **все бойцы**, **ваш выбор**, **выбор врага**, **информация о бойце**.
- **Полный баланс**: сила редкости отключена, у всех героев равная сила (x1.00) — побеждает знание механик и комбо. Хост начинает бой, реванш — кнопкой хоста.
- Работает между разными компьютерами одной сети; на одном компьютере второй экземпляр игры может подключиться к первому.

## Сила редкости (против бота)

В боях против бота, в выживании и кампаниях герой получает бонус к здоровью и урону за редкость:
НЕОБЫЧНЫЙ **+6%** · ЭКСКЛЮЗИВНЫЙ **+10%** · ЭПИЧЕСКИЙ **+13%** · МИФИЧЕСКИЙ **+20%** · ЛЕГЕНДАРНЫЙ **+35%** · DEVILY **+28%**. В бою с другом и ONLINE силы всегда равны.

## Фаталити

После победы над **БОССОМ** и в **бою с другом** экран темнеет: за **4.5 с** успейте набрать показанную комбинацию из 4 клавиш (W/A/S/D) — и ваш герой выполнит **фаталити**. У каждого стиля героя **3 вида фаталити** (серии ударов с хитстопом, магия, добивание — разрыв на куски, испепеление, сожжение души, электроказнь и др.), вариант выбирается случайно. Награда: **+150 монет и +5 самоцветов**. Ошибка сбрасывает прогресс комбинации.

## Бойцы (50)

**Стандартные:**
- **DEADY** — жнец душ. Бросок косы (возвращается через 3 с, без косы атака нет), костлявая рука из-под земли, мир душ с телепортом за спину врага.
- **LIGHTY** — человек-молния. Электрошок (оглушение 2 с), небесная молния (уворот — присед), вспышка (−60% получаемого урона на 3 с).
- **EMBERY** — пламенный берсерк. Огненный шар, столп пламени (уворот — прыжок), ярость (+50% урона на 5 с).

**Обычные (500 монет, у каждого свой уникальный набор механик):**
- **FROSTY** — ледяная королева. Ледяные осколки, **ледяные шипы из земли** (волна), ледяная броня.
- **TOXINY** — отравитель. Ядовитая очередь, ядовитый туман, вытягивание жизни.
- **SHADOWY** — убийца из тени. Теневой клинок, рывок тени (притягивание), шаг сквозь тень (телепорт).
- **STONY** — каменное сердце. Каменный удар (оглушение), землетрясение, каменная кожа.
- **WINDY** — хозяйка бури. Воздушная сфера, притягивание порывом, ускорение ветром.
- **SANDY** — повелитель песков. Песчаный снаряд, песчаная буря, песчаный поток.
- **SOLARY** — жрица солнца. Солнечный луч, столп света (уворот — присед), ореол (броня).
- **LUNARY** — дева луны. Лунный серп, лунная волна, исцеление луной.
- **NECROY** — владыка мёртвых. Рука из могилы, вампирская аура, мёртвая хватка.
- **PIXY** — искра леса. Волшебная пыльца, разряд пыльцы (оглушение), феичий прыжок (телепорт).

**Необычные (2000 монет, 4 способности):**
- **BANEY** — человек, мутировавший в паука. Паутина (обездвиживает на 1 с), призыв паучков-помощников, яд (процент от макс. HP за 4 с), паучий удар хвостом (гарантированный крит).
- **MAGNEY** — магнитный титан. Метеор из глубин (тяжёлый удар), магнитное притягивание, металлическая броня, электромагнитный разряд.
- **CRYSTAY** — кристаллическая дева. Веер кристаллов, кристальный купол (полный блок), кристальный дождь, мерцание (телепорт).
- **INFERNOY** — пылающая ярость. Испепеляющий луч, огненная волна, перегрев (+60% урона), прыжок-метеор с ударной волной.
- **MIRAGEY** — мастер миражей. Шаг миража (телепорт), веер иллюзий, иллюзорные оковы, дар миража (лечение).
- **PLASMY** — плазменное ядро. Плазменный снаряд, ионный луч (присед — уворот), плазменный щит (полный блок), очаг плазмы под врагом (уворот — прыжок).
- **TEMPESTY** — грозовой владыка. Вихрь (выдёргивает врага к вам), шквал воздушных сечей, грозовой фронт (град разрядов, уворот — присед), разряд (оглушение).
- **BONESY** — некромант-скелет. Костяное копьё, рука из могилы (уворот — прыжок), призыв костей, костяной саркофаг (полный блок).
- **SPECTRY** — призрак. Порыв духа (веер из трёх сгустков), сквозь стену (телепорт за спину), холод могилы (вампиризм 50%), стены духов (ряд столпов, уворот — прыжок).
- **BEASTY** — оборотень. Рвущий удар (гарантированный крит), прыжок хищника с ударом по области, звериная ярость (+45% урона), удар лапы в землю (уворот — прыжок).

**Эпические (5000 монет, 4-я способность — ульт):**
- **VAWYY** — водяной маг. Гейзер (подбрасывает врага в воздух), водоворот (затягивает и жмёт урон по тикам), цунами (стена воды через всю арену), **ГНЕВ ОКЕАНА** — вода закручивает врага в водоворот и разрывает.
- **GALAXY** — звёздный маг. Сингулярность (затягивает врага), комета с оглушением (уворот — присед), звездопад (уворот — присед), **ЧЁРНАЯ ДЫРА** — затягивает и разрывает врага.
- **BLADEY** — DPS-мастер клинков. Вихрь клинков (шесть клинков вокруг), клинок возмездия, танец смерти (+60% урона на 5 с), **КАЗНЬ** — серия смертельных разрезов. Сильнейший урон в комбо, но без защиты и уклонений.
- **VENOMY** — хирург чумы. Чумной токсин (10% HP за 5 с), рой миазмов, пожирание плоти (вампиризм 70%), **ПАНДЕМИЯ** — волна заразы. Слабый прямой урон, нет брони.
- **MAGMAY** — сердце вулкана. Поток лавы (уворот — прыжок), извержение (оглушение, уворот — прыжок), обсидиановая кожа (−60% урона), **СЕРДЦЕ ВУЛКАНА** — гольм взрывается лавой изнутри. Очень медленный.
- **GRAVY** — архитектор тяготения. Гравитационный колодец (стягивает врага), грави-импульс (оглушение 1.4 с), метеорит (уворот — прыжком), **КОЛЛАПС** — сингулярность сжимает врага. Нет лечения.

**Эксклюзивные (награда кампаний):**
- **GHOULEY** — награда «Кровавого замора». Кровавый бросок (гарантированный крит), жажда крови (вампирская аура), могильная лапа, **ПИР ГУЛЯ** — пожирает ослабленного врага вблизи.
- **ASHY** — награда «Пепельных пустошей». Пепельная буря, огненный столп, пепельный покров (−55% урона), **СМЕРТНЫЙ ЖАР** — волна пепла испепеляет врага на расстоянии.
- **PYROY** — награда «Трона пламени». Огненный шторм, метеор, ярость пламени (+50% урона), **АДСКОЕ ВОПЛОЩЕНИЕ** — взрыв адского пламени вблизи.
- **NECROMANCERY** — награда «Легиона костей». Зелёный властелин загробного мира: царство теней (неуязвимость + телепорт за спину), легион скелетов (4 скелета атакуют 2.6 с), аура пожирания (вампиризм 6 с), **ВЕЧНАЯ ТЬМА** — миф-ульта.
- **CHAOSY** — награда «Разлома реальности». Существо из разломов: осколки хаоса (веер из 4), хаос-рывок (телепорт за спину), безумный удар (гарантированный крит), **РАЗЛОМ РЕАЛЬНОСТИ** — миф-ульта.
- **TITANY** — награда «Кузни титанов». Последний из титанов: хватка титана (сжимает 2.2 с), гроза небес (тяжёлый удар, долгое оглушение), доспех богов (−65% урона), **УДАР ТИТАНА** — миф-ульта.

**Мифические (12000 монет, 4 спецприёма, миф-ульта на 1+4):**
- **NECROMANCERY**, **CHAOSY**, **TITANY** — те же бойцы, что и эксклюзивные награды, но доступны в магазине за монеты.

**DEVIL (только из сундука):**
- **DEVILY** — дьявол, пришедший из ада отомстить миру живых за то, что его там запечатали. Руки ада (уворот — прыжок), огненный дождь (уворот — присед), пожиратель душ (урон + лечение 70%), **ВОСКРЕСЕНИЕ АДА** — миф-ульта. Сильнейший набор в игре, но только из сундука и низкая скорость.

## Достижения

**191 достижение** с наградами в **монетах и самоцветах**: победы, боссы, волны, спецприёмы, ульты, добивания, парирования, комбо, страйки, травмы, покупки, кампании, уровень, сундуки, самоцветы, хедшоты, ловушки, крафты. Вкладка **AWARDS** с пагинацией.

## Прогресс и баланс

- Прогресс (монеты, самоцветы, уровень игрока и бота, EXP, купленные бойцы, кампании, достижения, статистика) сохраняется в `immy_save.json` (формат v3; для frozen exe — рядом с `IMMY.exe`). Фрагменты, артефакты, экипировка и настройки звука тоже в сейве.
- Баланс редкостей: у каждой редкости своя сумма статов (14/14/17/19/17/21/24), у каждого бойца есть **плюсы и минусы** — в умелых руках даже необычная редкость способна победить эпическую.
- Рендеринг: Canvas с тегами (`"bg"` рисуется один раз на смену состояния, `"dyn"` перерисовывается покадрово), лимиты частиц (220 частиц, 26 угольков), **110 FPS**.

```
main.py          — точка входа

build.bat        — сборка exe (git pull + PyInstaller)
immy/
  config.py      — константы, шрифты, палитра, кривая EXP, зоны, ловушки, артефакты
  util.py        — lerp/clamp/градиенты
  heroes.py      — данные 50 бойцов, способностей, спецприёмов, плюсов/минусов
  save.py        — сохранение прогресса v3 (+ фрагменты, артефакты, экипировка, настройки)
  campaign.py    — 23 кампании: ступени, сложность, награды, разблокировка
  achievements.py— 191 достижение и их проверка
  particles.py   — частицы с лимитами, кровь, угольки, всплывающий урон
  background.py  — 30 карт арен, фоны, иконки, факелы, ловушки
  artifacts.py   — 30 артефактов: природы, крафт, баффы (+7% за совпадение природы)
  dialogue.py    — сюжетные реплики ботов и боссов
  sound.py       — процедурная чиптюн-музыка + SFX (WAV-синтез, без файлов)
  fighter.py     — боец: физика, комбо, страйки, травмы, баффы артефактов, рендер
  ai.py          — ИИ бота: тактики, паны, уклонения, связки
  arena.py       — бой, раунды, зоны, ловушки, диалоги, ульты, ми-ульты, фаталити, HUD
  ui.py          — кнопки, монеты, самоцветы
  game.py        — окна, ввод, PLAY-подменю, настройки, магазин, артефакты, INFO, цикл
```
